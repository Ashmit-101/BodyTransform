Overview

From 5 years of gym photos
to an Instagram Reel

A complete, scriptable pipeline — runs entirely on your Mac, no cloud, no accounts.

~2h
Total time
30m
Manual sorting
2
Python scripts
9:16
Output format

The pipeline has 4 automated stages:

01
EXIF date extraction
Reads shot date from photo metadata, renames files chronologically
02
Body alignment
MediaPipe detects 33 landmarks → calculates spine angle → rotates to vertical
03
Scale normalization
Head-to-ankle distance → scaled to 82% of 1920px canvas height
04
CLAHE lighting normalization
Histogram equalization on L-channel only, blended 65/35 to avoid over-processing
05
Crossfade reel
MoviePy renders 1080×1920 MP4 with date labels + optional music

💡 Tip: Start with a single pose (e.g. front double bicep) to validate the output looks good before processing all your photos.

Step 1 of 6

Install tools

Everything you need. Takes about 5–10 minutes.

⏱ ~10 min

1a. Install Homebrew packages

# exiftool reads EXIF metadata from photos
# ffmpeg is used by MoviePy for video encoding
brew install exiftool ffmpeg

1b. Install Python packages

pip3 install mediapipe opencv-python moviepy pillow

1c. Install ImageMagick (needed for date label text in the reel)

brew install imagemagick

1d. Verify everything works

exiftool -ver                   # should print a version number
python3 -c "import mediapipe, cv2, moviepy; print('all good')"

⚠️ Python version: Use Python 3.9–3.11. MediaPipe has limited support for 3.12+. Check with python3 --version. If you're on 3.12, install 3.11 via brew install python@3.11 and use python3.11.

✓ Also download: The two script files (normalize.py and make_reel.py) provided alongside this guide. Put them somewhere convenient like ~/gym-reel/.

Step 2 of 6

Sort your photos

Manual sorting is faster and more accurate than any AI classifier for your personal photos.

⏱ 20–45 min

Set up this folder structure:

~/gym-reel/ ├── poses/ │ ├── front_relaxed/ ← standing front, arms at sides │ ├── front_double_bicep/ ← both arms flexed overhead │ ├── side/ ← side chest or side tricep │ └── back/ ← back double bicep or back lat spread ├── normalized/ ← script outputs here (auto-created) ├── normalize.py └── make_reel.py 
# Create the folder structure in one command
mkdir -p ~/gym-reel/poses/{front_relaxed,front_double_bicep,side,back}
mkdir -p ~/gym-reel/normalized

Photo selection guide

  • 8–12 photos per pose — aim for one every 3–6 months over 5 years
  • Full body in frame — head to feet must be visible for alignment to work
  • Consistent pose per folder — don't mix e.g. side chest and side tricep
  • Decent lighting — CLAHE helps, but can't fix a completely dark photo
  • Skip duplicates — pick the single best photo from each session
  • HEIC is fine — the script converts iPhone HEIC files to JPEG automatically

💡 Best pose to start with: Front double bicep. It's the most visually dramatic transformation pose and the most forgiving for alignment since both sides are symmetrical. Validate the pipeline works here before processing all poses.

Step 3 of 6

Normalize your photos

Run normalize.py on each pose folder. The script aligns, scales, and corrects lighting — then names the output files chronologically.

⏱ ~5–20 min (automated)

Run once per pose folder:

cd ~/gym-reel

# Syntax: python3 normalize.py <input_folder> <output_folder>
python3 normalize.py poses/front_double_bicep normalized/front_double_bicep
python3 normalize.py poses/front_relaxed      normalized/front_relaxed
python3 normalize.py poses/side               normalized/side
python3 normalize.py poses/back               normalized/back

Expected output for each photo:

Processing 11 photos → normalized/front_double_bicep

  ✓ [01/11]  Jan 2020  IMG_0421.jpg
        → scale=1.84x  rot=2.3°  body=831px
  ✓ [02/11]  Apr 2020  IMG_0834.jpg
        → scale=1.91x  rot=-1.1°  body=800px
  ✗ [03/11]  Jul 2020  IMG_1204.jpg
        → no body detected (try a clearer full-body photo)
  ✓ [04/11]  Oct 2020  IMG_1687.jpg
        → scale=1.77x  rot=0.8°  body=869px
  ...

Done: 10/11 normalized successfully
      1 failed — check those photos manually

⚠️ If a photo fails: The most common reason is the full body isn't in frame, or the photo is very dark. Try a different photo from around the same date. The script never deletes your originals — failed photos are just skipped.

🔍 MediaPipe accuracy note: Gym clothing (baggy shirts, hoodies) can confuse the pose detector. If you get a lot of failures, try running with a shirtless photo first to confirm the script works, then try the clothed ones. For persistent failures, move the photo to a manual_review/ folder and skip it.

Step 4 of 6

Review the output

5 minutes of eyeballing before you render saves you from a bad video.

⏱ 5–10 min

Open the normalized folder in Finder's column view to quickly scroll through all photos:

open normalized/front_double_bicep

What to check

  • Body is centered — shoulders should land at roughly the same horizontal position in every photo
  • Body height is consistent — person should appear the same size in every frame
  • Rotation looks correct — spine should be roughly vertical, not tilted
  • Lighting isn't wrecked — CLAHE should have improved dark photos, not destroyed well-lit ones
  • Files are named chronologically — 01_20200115_... → 11_20241203_...

Fix bad outputs

Simply delete any normalized photo you don't like. If the original was salvageable, re-shoot or substitute a better photo from that period and re-run normalize.py on just that one file:

# Normalize a single replacement photo
python3 normalize.py poses/single_replacement/ normalized/front_double_bicep/

✓ Good sign: When you flip through the normalized folder in Finder's preview, you should already be able to see the transformation. If it looks compelling as a slideshow, the video will look great.

Step 5 of 6

Make the reel

Run make_reel.py to render the final 1080×1920 crossfade video. One command per pose.

⏱ 5–15 min render time

Basic usage:

# Syntax: python3 make_reel.py <normalized_folder> <output.mp4>
python3 make_reel.py normalized/front_double_bicep reel_front_bicep.mp4

With music:

python3 make_reel.py normalized/front_double_bicep reel_front_bicep.mp4 --music track.mp3

All options:

python3 make_reel.py normalized/front_double_bicep reel.mp4
  --music    track.mp3     # background audio (.mp3, .m4a, .wav)
  --hold     2.5           # seconds each photo is fully visible (default: 2.5)
  --fade     1.0           # crossfade duration in seconds (default: 1.0)
  --no-labels             # disable date labels

Timing guide for 10 photos

--hold--fadetotal (10 photos)feel 2.51.026sRecommended start 3.01.531sSlower, dreamlike 2.00.821sFaster, punchy

🎵 Music tip: Reels with trending audio get 3–5× more reach. But for a first test, render without music to validate the visuals first. Add music in CapCut later (Step 6) using trending tracks without copyright issues.

Step 6 of 6

Polish & export

Optional but high-impact: add music, text overlays, and finishing touches before posting.

⏱ 10–20 min

Recommended: CapCut (free, on iPhone)

  • Import your reel_front_bicep.mp4 from Files app
  • Add trending audio — CapCut's library is copyright-safe for Reels
  • Add text overlay — e.g. "5 year transformation" at the start
  • Trim to exactly under 60 seconds for maximum Reels reach
  • Export at 1080p / 30fps — don't let CapCut compress it further

Or: add a simple title card with ffmpeg (no CapCut)

# Add "5 YEAR TRANSFORMATION" text at the start for 2 seconds
ffmpeg -i reel_front_bicep.mp4 \
  -vf "drawtext=text='5 YEAR TRANSFORMATION':fontsize=72:fontcolor=white:x=(w-tw)/2:y=h*0.08:enable='between(t,0,2)'" \
  -c:a copy reel_final.mp4

Instagram posting checklist

  • Aspect ratio: 9:16 ✓ (already correct)
  • Resolution: 1080×1920 ✓ (already correct)
  • Duration: 15–60 seconds for optimal reach
  • File size: Under 650MB — your output should be ~50–150MB, fine
  • Cover image: Set it to the most dramatic single frame (usually mid-transformation)
  • Caption: Include the timespan and relevant hashtags (#natty #transformation #bodybuilding)

Multi-pose version: combine all poses into one reel

Once you've validated the concept with one pose, concatenate all your pose reels with a section title between each:

# Combine multiple pose reels into one video
# (Create a text file listing the clips)
cat > clips.txt <<EOF
file 'reel_front_bicep.mp4'
file 'reel_side.mp4'
file 'reel_back.mp4'
EOF

ffmpeg -f concat -safe 0 -i clips.txt -c copy reel_combined.mp4

🎉 You're done. If the video looks good, this validates the entire concept. The core normalization pipeline (align + scale + lighting) is exactly what the app would do — you've just proven it works on your own photos before building anything.
